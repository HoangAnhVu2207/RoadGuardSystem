* B1: preserve every evidence's original location/source/time/accuracy. Never
  select the latest image, average positions, rank Capture/Exif/Manual by assumed
  trust, snap off-route points, or invent a radius/weight/confidence. PM with
  current Report/Case project authority may explicitly confirm one evidence's
  location and/or versioned route segments, with actor/time/reason/provenance.
  The confirmation serves matching only. It does not verify FIELD, coverage,
  eligibility or repair authority. Supervisor triage authority is unchanged.
  Use only the Case's pinned route/set/version. At boundaries return alternatives
  if a verified algorithm supplies them; do not arbitrarily select one. Confirmed
  segments precede topology neighbors; expansion remains explicit and project
  limited. Missing, unconfirmed and unusable GPS are distinct. Compute metres
  only with supported source/target CRS; keep unavailable distance/accuracy null.
  No target-accuracy model is approved, so do not fabricate overlap. Source,
  confirmation, geometry and targets participate in cursor staleness. Suggestions
  never automatically KEEP_NEW/LINK/REJECT/merge. No legacy location backfill.
* B3: only accepted current responsibility grants receiving PM exact item/source
  reads. Filter siblings/mixed packages. Retain immutable origin/provenance;
  neither source-project membership nor write/execution rights are implied.
  Recheck authority after onward transfer/revocation; no permanent historical grant.
* B6–B7: discover submissions, attempts, reviews and reuse separately by exact
  IDs/versions. Keep immutable lineage. A new supplement has no inherited review.
  Readiness, human review and final decisions differ. Reuse preserves source,
  file version/hash, actor/time/reason and ownership; metadata and content checks
  remain separate, scoped, and current.
* B5: preserve existing Supervisor candidate-fact/approved Fast Track observation

  broadcast notifications to all Supervisors.
* B10: reuse handover inventory and attach. Multiple documents need an explicit
  selection. Fresh aggregate road-coverage ETag after VERIFIED upload is required;
  document version is not that ETag. Keep file/scope/provenance guards.
* B12: unresolved/unused selection is distinct from history. Provide minimal
  history discovery without weakening selection/write guards. Do not transfer
  old safety automatically, reopen resolved obligations, or extend NORMAL to FT.
* B15: expose authoritative pinned policy/coverage versions and real errors/nulls.
  Do not manufacture sources/measurements, promote TEST_ONLY, or treat preflight
