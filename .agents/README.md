# RoadGuard guidance index (active development guidance)

`AGENTS.md` at the repository root is the short entrypoint. Rules below route source and evidence; module maps locate code and tests. Product meaning lives in `docs/product/`, wire definitions in `contracts/` only after per-contract adoption, implementation guidance in `docs/backend/`, decisions in `docs/decisions/` and `planning/refactor/02-decision-register.md`. Development starts from [the plan](../planning/development/README.md) and one assigned spec. RF tasks/reports in `planning/refactor/` are retained checkpoints and evidence.

Read `rules/evidence.md` and `rules/delivery.md` for every task, `rules/safety.md` for side effects, `rules/review-and-coordination.md` for self-review and shared work, and only the applicable module map. The active manifest keeps skills empty; retired RoadGuard skills remain retired.
