## Issue type and confidence

- `STATIC_MISMATCH`: source path contradicts a recorded target in a way visible without execution (R14 late attempt gate). Confidence **high in source reading**, medium in detailed target authority because the AI attempt protocol remains a proposal; isolated runtime testing is still needed.
- `CONTRACT_CONFLICT`: two in-repo contract surfaces or code paths disagree (R02/R06/R16). Confidence **high in syntax**, external compatibility unknown.
- `MISSING_IMPLEMENTATION`: operation/entity/action absent from the searched production source, while target draft names it (R05/R08/R11/R12/R15/R18). Confidence **high for this checkout**, deployed/external components unknown.
- `BUSINESS_DETAIL_UNKNOWN`/`POLICY_DETAIL_UNKNOWN`: approved direction was summarized but the input needed for executable thresholds, authority or retention/deletion is missing. No implementation value may be invented.
- `EVIDENCE_GAP`: source/tests exist but wire, DB or external behavior was not verified due RF-00 baseline and scope.
