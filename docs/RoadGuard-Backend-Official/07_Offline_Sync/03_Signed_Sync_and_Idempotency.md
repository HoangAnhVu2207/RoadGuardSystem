SchemaVersion=1, GUID nonempty, effectId=originId trong normal envelope, taskVersion decode base64 đúng8 bytes, core hash hex64, dependencies unique/không tự trỏ/bounded1000. Typed body khớp kind/action/resource; không nhận nhiều body cùng lúc. Historical FIELD_START replay chỉ dùng repository-loaded canonical typed effect, không generic bypass chữ ký/grant.

## Tiền điều kiện, luồng apply và kết quả

1. Service validate action/role/key, repository current actor/project guard lock và source device owned/current/not revoked. Verify signature + manifest; snapshot phải đúng source registration/original actor/task/assignment/task version. Import thêm grant/recipient proof như trang handover.
2. Stage persisted batch, origin binding và admission trong transaction; cùng ProjectId+OriginId nhưng body/kind/actor/device/resource khác ⇒origin_content_conflict. Source batch identity và payload hash giữ truy vết; attached signed payload phục vụ recovery.
3. Dependency DAG được xử lý theo ready origins. Chỉ predecessor COMMITTED/REPLAYED cho phép dependent. Nearest ancestor trên cùng FIELD task/repair resource cung cấp version mới; nhiều nearest candidates ⇒dependency_version_ambiguous. Không có ready effect ⇒PENDING_DEPENDENCY.
4. Mỗi item own serializable transaction: guard current source/grant; offline admission validator; shared FIELD `ApplyInternalInTransactionAsync` hoặc repair `ApplyInTransactionAsync`; validate canonical origin/effect/source; save effect và OfflineOperationResult cùng transaction, guard current quyền trước commit. Một item conflict không tự rollback item đã commit trước trong batch.
5. Final response guard current quyền/transport/accepted item proof lại. Batch HTTP200 gồm item state/code/effect/canonicalOrigin/durableAcknowledgment/serverReceivedAt/timeProvenance/lateness/outcome; client đọc từng item. ACK loss đọc batch/origin và có thể retry/reconcile; không xóa local conflict/unacknowledged queue.

## State machine, clocks và error flow

Item chưa apply → COMMITTED; exact durable effect retry → existing result/canonical replay. Failure lưu CONFLICT/STALE_SNAPSHOT/REJECTED/PENDING_DEPENDENCY với DurableAck=false; corrected/current source cần admission hợp lệ tiếp theo. Queue instruction `KEEP_UNACKNOWLEDGED_OR_CONFLICTED_ITEMS`. 403 current authority/grant denial không được biến thành protected historical success.

TimeProvenance `VERIFIED_ORIGINAL` chỉ khi độc lập xác lập original source, ngược lại UNCERTAIN; SyncLateness UNKNOWN nếu không verified finish. Với verified finish, received < finish+24h ⇒ON_TIME, đúng mốc hoặc sau ⇒LATE. VerifiedSyncDueAt chỉ finish+24h có nguồn. ClaimedFinishedAt vẫn lưu riêng; upload/sync time không thế original start/finish.

ND01 trong repair start core: verified original first start+expiry bắt buộc cho offline FT, current admission time phải trước original expiry, ClaimedAt không trước originalStart/không sau admission, first start nguồn khớp authorization và obligation, predicates current policy/coverage/location/measurement đều đủ; expiry được check lần nữa trước write. Sau expiry giữ evidence/finish/review phù hợp nhưng không start execution mới bằng grant cũ. `fast_track_offline_authority_not_activated` trong expiry branch không có nghĩa toàn bộ offline FT bị tắt.
