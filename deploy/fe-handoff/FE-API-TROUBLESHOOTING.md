# FE troubleshooting — preparation

Status: **NOT_VERIFIED / FE_INTEGRATION_PREVIEW**. This matrix uses inspected current source and bounded HTTP evidence. It does not close F08 or certify a final artifact. Match errors to the exact operation in [OpenAPI](openapi.json) and [the catalog](FE-API-CATALOG.json); do not assume every endpoint returns the same error body.

| Symptom | Likely boundary | FE action and diagnostic check |
|---|---|---|
|401 `auth_unauthorized` | Missing/invalid/expired credential, rejected Web cookie, inactive actor or role | Stop protected calls. Check HTTPS hostname and current session using the correct transport. An Authorization header takes precedence over cookies; remove accidental mixed-client configuration. Never log the credential. |
|401 `auth_session_revoked` on supported Bearer/session operations | Server-side revoked/expired session or role replacement | End the local authenticated workflow. Use explicit login or the operation's approved renewal behavior. Retrying the old token cannot restore authority. |
|403 `csrf_failed` | Missing/mismatched antiforgery cookie/header/identity | Call Web CSRF bootstrap with credentials included, especially after login or identity changes. Check the response `headerName`. Repeat a mutation only when its replay contract makes that safe. |
|403 `access_forbidden` | Current role/project/resource permission denied | Refresh authorized context. Confirm current membership and exact route project. A new CSRF token or operation key does not grant permission. Supervisor's global authority is operation-specific. |
|404 | Missing or deliberately concealed resource | Treat as unavailable. Do not probe other projects or claim the object never existed. C1 withdrawn and missing anonymous publications are both404. |
|400 `validation_error` | Invalid field/header/query or conflicting credentials | Compare exact required schema, enum, key/header syntax and query names. For discovery use `limit`; label lists use their own `pageSize` contract. Unknown query parameters can fail. |
|412 `concurrency_conflict` | Stale resource/assignment ETag | Fetch the current resource, compare state and let the user reconcile. Never strip `If-Match` or silently replace it and resubmit. |
|428 | Required header/precondition absent | Inspect that operation's required `Idempotency-Key`, `If-Match` or `If-None-Match`. A response may be empty; do not hide status by blindly parsing JSON. |
|409 `idempotency_key_reused` on supported mutations | Same scoped key used for a different command | Preserve original request/key for diagnosis. Use a new key only for a genuinely new operation, after resolving the original outcome. Never loop on new keys after a network failure. |
|Network error after POST/PUT/DELETE | Outcome unknown to client | First reconcile current state. Retry the identical key/payload only under the exact replay contract. Do not retry an internal AI callback from FE; current A1 replay remains a blocker. |
|Multipart transfer completed but evidence unavailable | Backend verification not complete or failed | Check the upload's server state through the authorized API. Object transfer alone is not evidence acceptance. Keep multipart IDs and part ETags private. |
|Private signed URL expires |300-second URL lifetime | Request access again through current authorization when applicable. Do not extend a signed URL locally or expose it in a bug report. Revocation does not retroactively cancel an already-issued unexpired URL. |
|Private file missing or denied | Object missing, incomplete verification or current scope denied | Use authorized metadata/state first, then content. Report the correlation ID and sanitized operation; Backend investigates storage in the owned environment. Do not ask FE to inspect production MinIO directly. |
|SQL/migrations/seed startup failure | Candidate configuration or dependency not ready | Verify the exact artifact and Compose project, readiness and documented migration/seed journal. Preserve volumes and original logs privately. Do not drop databases, rerun arbitrary SQL or delete volumes to force startup. |
|Browser reports CORS/TLS failure | Incorrect origin, trust or hostname | Use a trusted development certificate and exact configured FE origin. Check OPTIONS and browser network details without copying cookies. Do not disable TLS validation or use wildcard credentialed CORS. |
|Cursor validation fails | Corrupt or wrong-context discovery token | Start a new page sequence for the current actor/project/parent/filter. Pass returned cursors opaquely; no documented cursor expiration should be invented. |
|Mock AI job remains pending | Development worker/dependency/source failure | Check owned candidate health and job status; distinguish Mock AI from external provider acceptance. FE never supplies a production authentication bypass. |
|Notification pending or missing | Dispatcher retry, missing assignment, revoked generation or current authority | Check the genuine origin and exact recipient assignment. PM delivery can proceed with Supervisor unresolved. Do not fabricate an inbox notification or assign every Supervisor. |

Send a sanitized report using [the issue template](FE-ISSUE-REPORT-TEMPLATE.md). Include method/path, status, correlation ID, build identity and reproduction steps. Avoid private identifiers in screenshots or path copies where possible. Never send passwords, bearer/refresh tokens, cookies, private signed URLs, full connection strings or private media. Do not attach raw private SQL/HTTP test output to a public issue.
