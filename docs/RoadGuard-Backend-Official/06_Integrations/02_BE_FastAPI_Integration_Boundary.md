## Current worker flow / state machine

```mermaid
sequenceDiagram
    participant PM
    participant BE
    participant SQL
    participant Worker
    participant Storage
    PM->>BE: POST ai-mock-runs + key + source pins
    BE->>SQL: authorize + admit run/job/attempt/canonical manifest
    BE-->>PM: 202 + ETag/Location
    Worker->>SQL: claim durable lease/owner
    Worker->>Storage: read actual synthetic video, verify bytes/hash
    Worker->>Storage: write immutable frame; verify durable content
    Worker->>SQL: fenced complete + current sources + result/provenance
    PM->>BE: GET run/result/candidate
    BE->>SQL: current authority + source hash/pins
    BE-->>PM: result/facts or source conflict
```

Chuỗi này là **BE/synthetic implementation**, chưa phải chuỗi FastAPI quan sát ở production. `ProcessOneAsync` reauthorizes creator; reads dataset/files against manifest; creates deterministic fixture identities; matching recaptures snapshot before completion. IOException leaves durable lease recoverable, typed contract/data errors call FailAsync. Repository CompleteAsync needs owner/fence and current sources before attach; SQL transaction cannot make remote object write atomic, so immutable keys/hash + recovery handle crash boundaries. Generated object may exist before SQL attach; retention/reconciliation needed.

## Persistence, concurrency và callback gap

Synthetic persists `AiMockRun`, `AiResultProvenance`, `AiDetectionProvenance`, ProcessingJob/Attempt, AIDetection, frame StoredFile/FileScope and matching snapshots. Authorize before replay, canonical request/manifests/results hashes, leased owner complete/current source validation provide source-bound durability; not an assertion of every cross-process/provider scenario.

Legacy `ProcessingV2PersistenceService.ReceiveResultAsync` uses idempotency scope `(actor=null, project, "ProcessingAiResultReceived", key)` and fingerprint SHA256(detectionsJson+checksum). It checks attempt belongs to job, manifest/model/mode equal, raw file verified/project/checksum, then inserts detections and completes job. It **does not check latest/active attempt** and hash **does not bind job/attempt/manifest/model/mode**. FrameFileId/timestamp/bbox are stored in raw detection JSON, not full synthetic proof chain. [ProcessingV2PersistenceService.cs · ReceiveResultAsync L117](../../../RoadGuardSystem.Repositories/Implementations/Processing/ProcessingV2PersistenceService.cs#L117). Audit G02 is source-revalidated limitation; exploitation/late-callback race behavior remains NOT_VERIFIED. Do not tell provider compatibility callback inherits mock fencing.

Missing key428; incompatible source/state409; stale human retry412; invalid DTO422; wrong AI service credentials401/403; mock disabled404; unavailable result409. Callback raw source verified+checksum is metadata admission, not actual raw-result bytes read by this method. Same-key replay and current authority need operation-specific assertions; field presence alone does not make a secure provider protocol.
