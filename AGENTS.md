# RoadGuard task entrypoint (active RF-05 guidance)

The RF-05 activation manifest records owner acceptance on 2026-09-30. Locate the assigned task in [tasks](planning/refactor/tasks/), its latest checkpoint in [reports](planning/refactor/reports/), and the [module route](.agents/modules/README.md). Read only the relevant product, backend, contract, decision, code and test sources. Documents under docs/history are historical evidence, including embedded AGENTS.md copies; they are not active instructions.

Evidence labels are `CURRENT_VERIFIED` (observed implementation or executed check), `TARGET_CONFIRMED` (sourced owner decision), `PROPOSED`, `UNKNOWN`, and `HISTORICAL`. Current code establishes implementation, not business authority. Confirmed 32-44 requirements are in `docs/product/confirmed-decisions.md`; acceptance of a requirement does not accept a wire contract, schema, implementation or test. Historical 148 items and 701 excerpts are review material. A route candidate is not contract equivalence. A file in `contracts/` is active only when its status and adoption evidence say so.

Record branch, HEAD, dirty paths, scope and source evidence; implement the assigned independent work through focused verification, two-pass self-review, correction and a report under `planning/refactor/reports/` using `planning/refactor/templates/task-report.md`. Preserve unrelated changes and shared data. Ask for missing business, public-contract or data-loss decisions at the dependent checkpoint, then continue independent work. A clear assigned task does not need repeated approval for each reversible implementation step. Do not infer a decision from a V2 name or passing test.

Read [evidence](.agents/rules/evidence.md), [delivery](.agents/rules/delivery.md), [safety](.agents/rules/safety.md), [review and coordination](.agents/rules/review-and-coordination.md) and the relevant module map. Follow the [two-developer plan](planning/refactor/03-two-developer-plan.md) for proposed A/B slices; actual owners and shared writers are agreed at task start. Report actual self-review, peer review and integration evidence separately.
