For migrations compare generated operations, snapshot and mapping, including destructive column/drop/cascade changes and data backfill assumptions. Require a recovery/downgrade note; flag history rewriting only after establishing that the migration was shared/applied. Read-only review never modifies a migration.

Concurrency evidence needs independent contexts/connections and a controlled competing update, not merely two sequential saves on one tracked entity. Race-sensitive leases, holds and uniqueness must be tested at the enforcing layer. Report absent execution proof separately from defects proven by code.
